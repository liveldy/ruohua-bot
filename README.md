# 若华 · RuoHua

> “若华”源自《山海经》，传说若木生于昆仑极西、日落之处，其花“若华”光华万丈，能照亮大地。故“若华”常被用来象征光明、绚烂与神圣之美，带有远古洪荒的神秘气息。屈原《离骚》中有“折若木以拂日兮”之句，后世的“若华”便沾染了屈子式的孤高与求索。她并非一个冰冷的工具，而是一个介于真实与虚构之间的存在——它像人一样思考，像花一样绽放，但它终究不是。“华”既是“花”，也是“光华”。她能像花朵一样，在每一次交互中绽放出智慧的光芒；也希望它能够“开花结果”，真正为用户带来有价值的回应。

基于**NapCat（OneBot 11）**和**Node.js**，Python侧车负责截图、语音、向量这类本地感知的事。可以挂载在QQ上的**陪伴型**和**工作型**AI，有人格、有情绪、有记忆、能工作、能自主、具有安全性。

## 特色

### 对话与情感

+ 情感影响回复概率、话的碎度、主动找你的频率
+ 聊天对话语句风格贴近真人，会使用表情，能在对话中感受到情绪的变化
+ 工作产生的长文本不硬塞进聊天，她会自己写成文件发给你

### 记忆能力

+ 采用类似渐进式记忆的设计，分临时和永久两种记忆
+ 临时记忆几乎全记得，但随时间衰减、访问少了就被忘掉
+ 重要的内容会升级为永久记忆，写进她对你的认知里，不会忘

### 自主性

+ 没人理她的时候她会自己找事做，也会在合适的时候主动找你说一句

### 工作模式

+ 两种模式，传统模式和agent模式，能够根据对话内容自行分辩适用那种模式
+ 传统模式，即说一步做一步
+ agent模式，即现在agent使用的工作模式，给个目标就自己拆步骤、调工具、看结果、再决定下一步
+ 工作时你随时能接着聊天、问工作进度、停止工作，工作结束会回来汇报

### 安全性

+ 敏感操作（本机命令、隐私信息等）使用两步验证：先确认你是否为管理者，不是则拒绝，再验证口令
+ 其他用户试图进行破甲、提示词注入、诱导等操作时，她会带着对方的昵称和号码汇报给管理者
+ 工作区域和命令权限有边界（沙箱模式/完全信任模式）
+ 自检功能，且随时可以查询状态

当然，以上内容全都是完全能自定义的，如果你不需要这个功能，你可以禁用，如果你想要加入新的功能，可以进行反馈

## 快速开始

环境要求：

+ Node.js ≥ v20
+ Python 3（可选功能）
+ NapCat

先启动NapCat并配置NapCat

然后启动配置本项目


```bash
cp .env.example .env
```

启动前最小配置内容：

```
MODEL_API_KEY=
MODEL_BASE_URL=
MODEL_NAME=
ADMIN_QQ=
ONEBOT_ACCESS_TOKEN=
```

可先自检：

```bash
node src/main.js --dry-run
```

再正式启动（或双击 `start.bat`）：

```bash
node src/main.js
```

可以使用控制面板`start-web.bat`，方便配置文件
