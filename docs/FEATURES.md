# 她是什么样的

人格、情绪、记忆、感知、自主性都落在代码里，不是提示词上的装饰。
参数都放在 `config/`，各节点名对应的文件。

## 人格化

- 不说「作为一个AI」那套：`config/persona.json` 的 `style.forbidden` 里那几句会被直接删掉。
- 回你的是短句，一条一条发，中间有打字停顿（按字数算，上限 3.5 秒）；分段上限与停顿区间在 `style.segments`。
- 多用逗号少用句号，情绪强烈时用问号感叹号，无语时单发一个逗号 —— 规则写在 `style.punctuation`。
- 表达情绪靠 QQ 内置表情与表情包：正文里的 emoji、颜文字会被换成 `face` 段（`expressions.emojiToFace` / `kaomojiToFace`）。
- Markdown 记号会被抹掉（聊天窗口不渲染它）。

**表情包**（`config/sticker.json`）

- 管理员发一张图，她认下这张图、让模型自己看懂它是什么意思、存进库（`learnFromAdmins`）；别人发的默认只记个印象（`learnFromOthers`）。
- 库里每张有标题、含义、时机标签、用过几次、谁教的。可以在控制面板的「表情包」页改这些，也能让模型「自动识别」，还能删掉一张。
- 该发的时候**单独发一条**（`standalone`），不跟文字挤在同一条消息里 —— 这是表情包与 QQ 内置表情的区别。
- 挑图按「时机标签 + 标题」的字面命中、当前情绪、好感度加权，另有冷却（`sendChance` 0.16、`cooldownMs` 120000）。
- 别人发的表情包，只要在库里就认得出，在上下文里写成 `[表情包：得意]`；库里没有的图她也真看一眼（同一条消息最多两张）。
- 图片本体在 `stickers/`，索引在 `data/stickers/index.json`。细节见 [`docs/STICKERS.md`](STICKERS.md)。

## 情感

- 每个人一套好感度（0–100），以及当下的情绪：平静 / 开心 / 生气 / 委屈 / 疲惫 / 关心。
- 好感度会随时间回落，半衰期 168 小时、朝 40 收敛；一句夸奖 +3、道谢 +2、被骂 −6，权重在 `deltas`。
- 情绪影响三件事：回不回复、话说得碎不碎、主动找你的频率。生气时 `replyChance` 0.75，疲惫时 0.7 且分段拉长；开心时话更多、也会更常主动找你。
- 每一轮对话之后判一次情绪：`emotion/judge.js` 用一次轻量模型调用给出情绪走向、好感度增减与这段对话的记忆价值；判不出来就回退到中性默认值，不报错。
- 状态落在 `data/emotion.json`。参数在 `config/emotion.json`。

## 记忆

- 分临时与永久两种。临时记忆半衰期 72 小时，访问少了就被忘掉；够重要（importance ≥ 0.75）或者命中「刻骨铭心」关键词的，升级成永久记忆，写进她对你的认知里，不会忘。
- 召回按 **相关性 × 0.5 + 新鲜度 × 0.3 + 重要性 × 0.2** 排序，取前 12 条。相关性优先走向量（Python 侧车），侧车不在就退化成关键词兜底。
- 每 30 分钟巩固一次：合并相似的、晋升该记住的、丢掉该忘的。
- 每人一套，按人存在 `data/memory/`。参数在 `config/memory.json`。

## 感知

- **看**：聊天里的图片能看懂；库里认得的表情包直接写含义，其余图片交给视觉模型看一眼。必要时她自己截屏再看（`screen_capture`，优先走侧车，侧车不在用 PowerShell 兜底）。
- **说**：发消息、发文件、发表情。
- **听**：语音转文字在 Python 侧车（`POST /asr`，装了 `faster-whisper` 才有）。会话里收到语音只当作一个「对方发来了语音」的信号，正文位置留一个 `[语音]` 占位。
- 识图优先用模型自己的能力：`config/model.json` 的 `visionModel` 留空就用主模型。
- 长文本不硬塞进聊天，她**自己写成文件发给你**（`persona.style.maxCharsBeforeFile`，默认 800 字）。
- 侧车的能力清单与可选依赖见 [python/README.md](../python/README.md)。

## 自主性

- 没人理她（空闲 45 分钟）她会自己找事做：回忆旧记忆、翻看工作区、查资料写笔记、写点东西、给自己出个题。每小时看一次，每天最多 12 次。
- 主动找你说一句有节制：最小间隔 90 分钟、每天最多 8 次、静默时段 23:30–07:30，还受情绪系数影响。
- 定时任务到点会来找你，这件事在同一个循环里：20 秒轮询一次 `data/schedule.json`。固定的任务可以写在 `config/tasks.json`。
- 参数在 `config/autonomy.json`。

## 工作

- 两种模式：**传统模式**（说一步做一步，最多 8 步）与 **agent 模式**（给个目标就自己拆步骤、调工具、看结果、再决定下一步，最多 24 步）。由 `brain/decision.js` 按对话内容选。
- 干活时她不会把你锁住：任务在后台跑，你随时能接着聊天、问进度（`/任务`）、喊停（`/停止`），默认每 6 步汇报一次，干完会回来汇报。
- 结果太长就变成文件发出来（`resultAsFileThreshold`，默认 800 字）。
- 聊天本身也带工具（`agent.chatTools`）：聊着聊着她能自己去查文件、看系统状态、联网，一轮最多 3 步（`chatMaxSteps`）。
- 同时最多跑 3 个任务，单步超时 120 秒，单个任务 900 秒。参数在 `config/agent.json`。

## 安全

- 敏感操作走**两步验证**：先看你是不是管理者（`config/security.json` 的 `admins`），不是就婉言拒绝；是的话再问**暗号**。
- 暗号不是让你背口令：她揉进一句日常对话里让你自己领会，问法与答法都不唯一，同一个问法在 20 分钟内不会重复，答错 3 次或超过 15 分钟作废，通过后 20 分钟内免验证。
- 要口令的是真会改东西的动作：`shell`、`file_write`、`file_delete`、`process`、`system_setting`、`send_file`、`self_modify`。读文件与联网不在这一档 —— 她要能自己去查。
- 有人试图破甲、提示词注入、诱导敏感操作时，她带着对方的昵称和号码汇报给管理者（关键词打分 + 可选的模型判定，同一个人 5 分钟内不重复上报）。
- 工作区域与命令权限有边界：`boundary.mode` 在 `sandbox`（默认，限路径、限命令）与 `trusted`（完全信任）之间切。
- 控制面板默认只监听 `127.0.0.1`；要听外网必须同时打开 `allowRemote` 并设 `token`。

## 自知

- `/状态`（只打「状态」也行）：启动时间、跑了多久、模型、已用 token、余额、上下文占用、记忆条数、任务数、定时任务、OneBot 连接、侧车、情绪与好感度。取不到的值她写「查不到」，不编。
- 启动时做一次自检，把结论连同问候一起发给管理者；`/自检` 随时可以再做一遍。查的是：配置文件、数据目录、模型 API Key、模型接口连通、OneBot 连接、Python 侧车、日志目录、沙箱边界、口令池、Node 版本、磁盘剩余。
- 操作日志与对话日志落在 `data/logs/`：`app-<日期>.jsonl`、`conversation-<日期>.jsonl`、`operation-<日期>.jsonl`。
