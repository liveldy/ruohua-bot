# 本地化（i18n）

程序文件里不出现任何面向用户的文字，一律写成 `t('命名空间.键')`；文字放在本地化键文件里，
管理员能在控制面板的「本地化键」页改，改完落到 `data/locales/zh-CN.json`。

```js
import { t } from '../i18n/index.js';                  // 路径相对本文件
t('agent.runner.finish');                              // 静态键
t('agent.runner.progress', { done: 3, total: 12 });    // 占位符
```

- `t()` 是**同步**的，模块顶层就能调，不用把本地化器一层层传下去。
- 键必须是**字面量**：不许 `t('a.' + name)`、不许模板串，体检认不出会当成缺键；按变量选句子就写映射表 `MAP`。
- 占位符写 `{名字}`，参数以对象传入；找不到对应参数时占位符原样留着。
- 找不到键时 `t()` 返回**键本身**并记进 `missing`，体检与单测都会拦。
- 多行长文本（提示词这类）**整段一个键**，不要一句一句拼。

## 本地化键文件

`src/i18n/locales/zh-CN/<命名空间>.json` —— **文件名就是命名空间**，键必须以「命名空间.」开头，
扁平不嵌套，UTF-8 无 BOM、LF 行尾：

```json
{
  "brain.reply.sent": "发出去 {count} 条",
  "brain.reply.quoted": "（在回复 {name} 的消息：「{text}」）"
}
```

命名空间：`app` `agent` `brain` `onebot` `memory` `emotion` `persona` `security` `system`
`perception` `autonomy` `llm` `config` `web` `sticker` `i18n` `sidecar`。

**程序要用的字符**（标点表、颜文字、表情符号）不是给人读的文字，用 `\uXXXX` 写，体检脚本看到的是转义而不是中文；没有「这行先跳过」之类的例外口子。

```js
punctuation: { prefer: '\uFF0C', allowed: ['\uFF0C', '\u3002', '\uFF1F'] }  // ，。？
```

## 面板与 Python

- `web/index.html` 的文字节点标 `data-i18n="键"`、属性标 `data-i18n-attr="placeholder:键,title:键"`，启动时由 `app.js` 用 `/api/i18n` 拿到的键表填进去；`web/app.js` 用同一个 `t()`。
- `python/i18n.py` 读同一批本地化键（只用标准库）：`configure(root_dir)` 挂上覆盖文件，
  没有对应参数的占位符原样留着。

## 管理员改文字

- 面板「本地化键」页列出全部键、当前值、默认值，可搜索、可编辑、可还原成默认。
- 保存写到 `data/locales/zh-CN.json`（只写与默认不同的键），**覆盖优先于代码默认**；
  `configureI18n({ locale, overrideFile })` 在 `main.js` 装载配置后调一次，`i18n().reload()` 重读覆盖文件。

## 守卫

```bash
node tools/dev/check-i18n.mjs          # 全量报告
node tools/dev/check-i18n.mjs --quiet  # 只报错，不列未使用的键
```

体检三件事：`src/**`、`web/**`、`python/**/*.py` 里出现中文字面量 → 报错；代码里 `t('x.y')` 用到的键
在本地化键文件里没有 → 报错；`web/index.html` 里没走 `data-i18n` 的中文 → 报错。同一套检查也做成了
单测 `tests/unit/i18n.test.js`（`npm test` 里会跑）。
