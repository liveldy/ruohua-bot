# 使用（USAGE）

怎么把她跑起来、跟她说哪些话、有哪些做不到的。配置项见 [CONFIG](CONFIG.md)，控制面板见 [WEB](WEB.md)。

## 环境要求

| 需要 | 说明 |
| --- | --- |
| Node.js ≥ 20 | `package.json` 的 `engines` 写的是 `>=20.11` |
| NapCat | QQ 协议端（OneBot 11），接法见 [NAPCAT](NAPCAT.md) |
| 一个模型接口 | OpenAI 兼容；默认按 DeepSeek 的地址与模型名配 |
| Python 3 | 可选。只有截图、语音转文字、向量化这些本地能力要用，不装也能纯 Node 跑 |

依赖只有 `ws` 一个：

```bash
npm install
cp .env.example .env
```

## 最小 .env

这几项是起得来的底线——`MODEL_BASE_URL`、`MODEL_NAME`、`ADMIN_QQ` 少一个就直接以配置错误退出，
少了密钥或 token 则是连不上、被接口拒（宁可起不来，也不带病运行）：

```
MODEL_API_KEY=sk-xxxx
MODEL_BASE_URL=https://api.deepseek.com/v1
MODEL_NAME=deepseek-chat
ADMIN_QQ=你的QQ号
ONEBOT_ACCESS_TOKEN=NapCat里配的token
```

`ADMIN_QQ` 是敏感操作的把关人，多个号用逗号隔开。全部键与分组见 [CONFIG](CONFIG.md)。

## 启动

| 参数 | 作用 |
| --- | --- |
| —（不带参数） | 正常启动：自检 → 连 NapCat → 起自主性与控制面板 |
| `--dry-run` | 只自检，不连 QQ |
| `--offline` | 跳过模型接口连通检查（没网 / 省流量时用） |
| `--no-sidecar` | 不起 Python 侧车（截图、语音、向量降级） |
| `--no-autonomy` | 关掉空闲活动与定时任务 |
| `--no-web` | 不起控制面板 |
| `--web-port 8790` | 换控制面板端口（默认取 `config/web.json` 的 `port`，8787） |
| `--log-level debug` | 日志级别，debug / info / warn / error |
| `--config-dir <目录>` | 换一个配置目录（多开时用） |
| `--help` | 打印用法 |

```bash
node src/main.js --dry-run     # 先自检
node src/main.js               # 正式启动；也可以双击 start.bat
```

控制面板跟着主程序一起起（http://127.0.0.1:8787），`start-web.bat` 也是启动主程序。
日志里出现「已连上 OneBot 服务端」与「登录账号 …」就算活了。

## 跟她说这些

直接说话就行，闲聊、问事、让她干活都可以。另有这些指令：

| 指令 | 别名 | 作用 |
| --- | --- | --- |
| `/状态` | `/运行状态` `/系统状态` | 启动时间、运行时长、模型与接口、token 用量、余额、上下文占用、记忆与任务、连接、侧车 |
| `/任务` | `/进度` `/工作` | 手头在跑什么、走到哪一步 |
| `/停止` | `/中断` `/别做了` | 把手头的事全停下 |
| `/自检` | `/体检` | 重新体检一遍（仅管理者） |
| `/记住 <内容>` | — | 让她把这句话当永久记忆（仅管理者） |
| `/定时 <时间> <事情>` | `/计划` | 加一条定时任务（仅管理者） |
| `/忘记` | `/清空记忆` | 清掉她对你的记忆，同时清掉当前会话上下文（仅管理者） |
| `/重开` | `/清空上下文` | 只清当前会话的上下文，不动记忆（仅管理者） |
| `/帮助` | `/能做什么` | 指令一览 |

英文写法（`/status` `/tasks` `/stop` `/selfcheck` `/remember` `/schedule` `/forget` `/reset` `/help`）同样认。
别名去掉斜杠、**整条消息正好是这个词**才算命中——打「状态」「自检」她照做，「我现在的状态不太好」这种正常说话不会被当成命令。

`/定时` 的写法是「时间 + 事情」，时间取第一个空格前的部分：

| 写法 | 意思 |
| --- | --- |
| `每天08:00` / `每天8点` / `每天早上八点` / `08:00` | 每天这个点 |
| `+30m` / `半小时后` / `2小时后` | 一次性，过这么久之后 |
| `10m` / `30m` / `每30分钟` / `每隔十分钟` | 每隔这么久一次 |
| `2026-10-27T09:00` | 一次性，到点触发 |

中文口语要带上「每天」才认得出来（`每天晚上八点` 可以，光写 `晚上八点` 不行）；实在认不出，她会让你说清楚点。

例：`/定时 每天08:00 提醒我交电费`。她建的定时任务落在 `data/schedule.json`；写在 `config/tasks.json` 里的固定任务启动时也会合并进来。

干活的两种模式（说一步做一步的传统模式、给个目标自己拆步骤的 agent 模式）由她自己判定。任务在后台跑，
期间你随时能接着聊、用 `/任务` 问进度、用 `/停止` 喊停；干完她会回来汇报，结果太长就写成文件发给你。

## 已知限制

- 单进程、单账号。要同时挂多个 QQ 号得用 `--config-dir` 多开，且各自的 `data/` 与端口不能撞；别让两个实例连同一个 NapCat、写同一个 `data/`。
- 识图**优先用模型自己的能力**：`config/model.json` 的 `visionModel` 留空就用主模型（DeepSeek 这类多模态模型自己就能看图）。主模型看不了图时，图能存下来，但标题与描述先空着，得在面板的「表情包」页手写或换个视觉模型。
- 语音转文字要装 `python -m pip install faster-whisper`，不装就没有「听」的能力。
- 决策、情绪判定、记忆提炼各占一次模型调用；想省钱可以把 `config/model.json` 里这些角色的 `maxTokens` 调小。
- 群聊默认必须 @ 她才理（引用她自己发的消息也算）；怕吵就在 `config/bot.json` 里配 `groupWhitelist`。
- 表情包挑图按「标签 + 标题」的字面命中加权重（标签就是「什么时候发这张」；内容描述只给人看、不参与匹配），还没有向量相似。
- 协议端给的图片常常是「本地缓存文件 + 一个 http 地址」：裸文件名由 `src/perception/image-source.js` 去协议端缓存目录里找回来
  （`<文档>/Tencent Files/<QQ号>/nt_qq/nt_data`，找到的目录自动放行），地址那条则直接下载。协议端把图放在别处时，
  把那个目录加进 `config/sticker.json` 的 `allowedRoots`（默认只读 `stickers/` 与 `data/`）。
- 她写出来的文件统一是 UTF-8；`data/`、`work/`、`reports/` 是运行产出，不参与编码体检，也不该进版本库。
- 用自己常用的 QQ 号挂协议端有被风控的风险，建议用小号。
